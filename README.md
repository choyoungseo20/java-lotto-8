# java-lotto-precourse
# 로또

---

## 프로젝트 개요
- 본 프로젝트는 간단한 로또 발매기를 구현하는 프로젝트입니다.
- 사용자가 입력한 구입 금액만큼의 로또를 발행하고, 당첨 번호와 비교하여 당첨 통계(당첨 내역, 수익률)를 계산합니다.

--- 

## 기능 요구 사항

### 1. 로또 발행
- 로또 번호는 **1~45** 범위의 숫자로 구성
- 1개의 로또는 **중복되지 않는 6개의 숫자**
- 구입 금액에 따라 로또를 자동으로 발행 (1장 1,000원)

### 2. 당첨 번호 추첨
- 중복되지 않는 6개의 번호 + 1개의 보너스 번호

### 3. 당첨 기준 및 상금
| 등수 | 기준 | 상금 |
|------|------|------|
| 1등 | 6개 번호 일치 | 2,000,000,000원 |
| 2등 | 5개 번호 + 보너스 번호 일치 | 30,000,000원 |
| 3등 | 5개 번호 일치 | 1,500,000원 |
| 4등 | 4개 번호 일치 | 50,000원 |
| 5등 | 3개 번호 일치 | 5,000원 |

### 4. 입력 및 예외 처리
- **구입 금액 입력**
    - 1,000원 단위로 입력
    - 1,000원으로 나누어떨어지지 않거나 1,000원 미만 입력 시 예외 발생
- **당첨 번호 입력**
    - 쉼표(,) 구분으로 6개의 번호 입력
- **보너스 번호 입력**
    - 1개의 번호 입력
- 잘못된 입력 시 `IllegalArgumentException` 발생
    - 에러 메시지는 반드시 `[ERROR]`로 시작
    - 예: `[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.`

### 5. 출력
- **발행한 로또 수량 및 번호** 출력 (오름차순 정렬)
- **당첨 통계**

## 구현 기능

### 로또
- [x] 로또 번호들을 가진다.
  - [x] 로또 번호들의 총 개수는 6개이다.
  - [x] 로또 번호는 중복일 수 없다.
  - [x] 로또 번호는 1부터 45 사이의 숫자이다.

### 로또 번호 생성
- [x] 1~45 범위의 중복되지 않은 6개의 무작위 정수를 생성한다.

### 구입 금액
- [x] 구입 금액을 가진다.
  - [x] 구입 금액은 1,000원 단위이다.
  - [x] 구입 금액은 1,000원보다 작을 수 없다.

### 당첨 번호
- [x] 당첨 번호들을 가진다.
  - [x] 당첨 번호들의 총 개수는 6개이다.
  - [x] 당첨 번호는 중복일 수 없다.
  - [x] 당첨 번호는 1부터 45 사이의 숫자이다.
- [x] 보너스 번호를 가진다.
  - [x] 보너스 번호는 당첨 번호와 겹칠 수 없다.
  - [x] 보너스 번호는 1부터 45 사이의 숫자이다.

### 당첨 순위
- [x] 당첨 순위를 가진다.

### 당첨 결과
- [x] 각 순위 별 당첨 결과를 저장한다.
- [x] 총 당첨 금액을 계산한다.

### 당첨 통계
- [x] 당첨 순위에 해당하는 로또 개수를 계산한다.
- [x] 수익률을 계산한다.
  - [x] 소수점 둘쨰 자리에서 반올림한다.

### 입력
- [x] 구입 금액을 입력받는다.
- [x] 당첨 번호를 입력받는다.
- [x] 잘못된 입력을 받으면 해당 위치부터 입력을 다시 받는다.

### 출력
- [x] 구매한 로또 번호들을 출력한다.
- [x] 당첨 통계를 출력한다.
  - [x] 총 수익률을 출력할 때, 천 단위 구분을 해야한다.
  - [x] 총 수익률을 출력할 때, 소수점 첫째 자리까지 표시해야 한다.
